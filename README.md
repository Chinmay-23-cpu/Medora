# Medora — Medical Imaging & AI-Assisted Care

Prototype platform for brain, heart, and lung image review. Upload a scan, review visual explanations and a triage summary, then find nearby specialists and book an appointment.

**Not a medical device.** Findings are simulated decision-support visuals for demonstration only and must not be used for diagnosis or treatment.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000
